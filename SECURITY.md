# Security Policy

Apache Caldera (incubating) follows the security process of the Apache
Software Foundation (ASF).

## Reporting a security issue

Report security issues privately by email to
[security@apache.org](mailto:security@apache.org). The ASF Security Team
passes each report to the project's private mailing list.

Do not report security issues in public GitHub issues, pull requests,
discussions or mailing lists.

For how the process works and what a report should contain, see:

- <https://www.apache.org/security/>
- <https://security.apache.org/>
